# Actividad Formativa 2: Simulación y Análisis de Señales con la Transformada de Fourier

## Descripción
Este proyecto implementa la generación, análisis y transformación de señales en el dominio del tiempo y de la frecuencia utilizando **Python**, aplicando la librería **NumPy** para el cálculo de la Transformada Rápida de Fourier (FFT) y **Matplotlib** para la visualización de resultados.

## Contenido del Repositorio
- `analisis_fourier.py`: Script principal con la implementación de las señales, cálculo de la FFT y comprobación de propiedades
